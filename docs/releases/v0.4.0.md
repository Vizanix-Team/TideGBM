## TideGBM 0.4.0

Temporal ordered gradient boosting for panel and market data — histogram GBDT with TORB, purged evaluation, and pairwise ranking for cross-sectional IC.

### Install

```bash
pip install tidegbm
```

Optional extras:

```bash
pip install tidegbm[onnx]    # ONNX export
pip install tidegbm[bench]   # LightGBM + CatBoost benchmarks
```

Requires **Python 3.10+** and a **C++17 compiler with OpenMP** when installing from sdist. Pre-built wheels: Linux, macOS, Windows (amd64).

### Highlights

- **TORB** — temporal ordered residual boosting with auto time buckets
- **Pairwise objective** — within-date LambdaMART-style ranking; beats LightGBM mean IC on the public 30-name stand (horizons 1/3/5/10)
- **Leak lint** — strict mode blocks lookahead features at fit time
- **Histogram engine** — column-major C++17 core, OpenMP; optional CUDA wheels
- **sklearn API** — `TideRegressor`, `TideClassifier`, `TideRanker`, purged `WalkForwardSplit`
- **Model I/O** — binary TGBM v3, JSON, optional ONNX

### Quick start

```python
from tidegbm import TideRegressor, WalkForwardSplit

model = TideRegressor(horizon=1, n_estimators=200, max_depth=6, objective="pairwise")
model.fit(X_train, y_train, timestamp="ts", entity="symbol")
pred = model.predict(X_test)
```
