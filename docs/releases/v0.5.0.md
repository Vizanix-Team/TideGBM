## TideGBM 0.5.0

Hot-path rewrite of the C++ trainer plus one new opt-in quality feature. Every speed change is semantics-preserving: fold ICs on the 30-name market stand are identical to 0.4.0 to five decimals.

### Install

```bash
pip install -U tidegbm
```

Requires **Python 3.10+** and a **C++17 compiler with OpenMP** when installing from sdist. Pre-built wheels: Linux, macOS, Windows (amd64), CPython 3.10 to 3.12.

### Speed

- **TORB prefixes no longer rescan the data per bucket.** The causal prefix of each bucket is a contiguous range, so cuts are computed once per fit and the per-tree loop is a single sweep. `O(n_buckets * n)` becomes `O(n + n_buckets * nodes)`, with bit-identical leaf values.
- **Rank objectives no longer rebuild a hash map every iteration.** Group boundaries come from one scan; the per-group loop is parallel.
- **PAIR split evaluation is fused and parallel.**
- **Histogram bins are interleaved** (gradient, hessian, count together), and histograms are zeroed and allocated once per split instead of several times.

### Quality

- **`uniqueness_weight=True`** (default off): weights each row by the average uniqueness of its label (Lopez de Prado). Also exposed as `average_uniqueness` and `uniqueness_weights`. On the market stand the effect is within noise, which is why it ships opt-in.
- **Ranking objectives report a ranking loss.** `evals_result_["train"]` for `rank` / `pairwise` now reports negative mean within-group correlation instead of a meaningless squared error. This changes the values of that series for ranking fits.
